# 线站值班职责的代理授权

跨站代班、查阅和交接记录的许可来源的本地资料以 JSON 保存，全部身份、系统与输入均为合成。资料服务只回放各参与方提供的事实。

需要 Python 3.11。运行 `python3 -m unittest -v` 核对项目资料和本地接入。运行 `python3 replay.py` 启动回放服务，默认监听 `127.0.0.1:8765`。访问 `/streams` 查看资料名称，`/streams/名称` 读取相应资料，`/timeline?through=60` 读取截至演练时刻 60 收到的事件。也可直接读取 `data/` 中的原始文件。

## 资料约定

roles 来自排班部门，duty 是人员受管理的职责。grants 是初始委托记录，parent 为空表示由当班职责直接委托，否则指明许可来自哪条上游代理。时间按 starts/start 含端点及 ends/end 不含端点解释。handover 是工作台已有的待签交接记录，principal 为待签所代表的责任人，grant 为提出办理时选用的代理来源。引用的人物编号由统一身份名录分配。
timeline 中冻结事件指明一条代理来源。负责人重发是明确的新交接选择，不是撤销结果的副本。调离信息由排班部门提供。transfers 给出跨站仪表移交单、两站责任人与交接内容修订，timeline 的移出和接收确认引用相应修订。
